Release the first stable version.
The plugin has been stable for years, so staying on `0.x` no longer gave us any benefit.
Apart from the changes below, it works the same as `0.12.0`.
From now on, breaking changes such as dropping a Node.js or Prettier version are major releases, and `elm-format` updates, which may change how code is formatted, are minor releases.
